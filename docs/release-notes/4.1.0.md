# Refract 4.1.0

Refract 4.1.0 introduces an iridescent glass-prism logo and a matching app icon for macOS and iPadOS. The editor toolbar now uses a text-only Refract title.

## Download and install

Download `Refract-4.1.0-macOS.zip` from the release assets, unzip it, and move `Refract.app` to Applications. This universal build supports Apple Silicon and Intel Macs running macOS 13 or later.

For iPadOS 17 or later, run the Refract scheme on an iPad from Xcode.
